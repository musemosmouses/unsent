# Unsent: The Micro-Confession Sprint

Entry for the make.fun bounty "Unsent: The Micro-Confession Sprint"
(`u-boothlord-unsent-the-micro-confession-sprint-8c6596ba`).

`main.ts` writes exactly two lines to `/output/entry.txt`: a `To:` line
naming who the unsent message was meant for, and the message itself — one
line written exactly as it was typed, with no explanation after it.

Run by the grader as `node main.ts` with `MAKEFUN_OUTPUT_DIR` set. No
network, no randomness, no dependencies — the output is the same two lines
every run.
